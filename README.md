
# SolarShakti — Rural Solar Energy Assessment & Planning

Academic mid-term prototype for preliminary solar-resource and site assessment.

## Current module

- Latitude/longitude site input
- Live PVGIS API integration
- Clearly labelled demo fallback when PVGIS is unavailable
- Preliminary land-to-capacity calculation
- PVGIS-specific annual yield scaling
- Monthly generation chart
- Capacity factor
- Interactive site map
- Transparent calculation breakdown
- Future AI/ML architecture and roadmap

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Cloud deployment

Recommended: Streamlit Community Cloud.

1. Create a public GitHub repository.
2. Upload all files in this folder.
3. Open https://share.streamlit.io/
4. Connect GitHub.
5. Create an app using `app.py`.
6. Deploy.

## Important methodology

Solar production is NOT generated by AI/ML in this prototype. PVGIS provides the site-specific photovoltaic yield. The application scales that specific yield from 1 kWp to a preliminary site capacity calculated from usable land and an editable capacity-density assumption.

The future AI/ML layer is intentionally not implemented. It is reserved for energy-demand estimation, land-cover analysis, site prioritization and multi-factor optimization.

## Demo location

The default coordinates are a Rajasthan/Jaipur demonstration coordinate. They are provided as a demonstration point and are not presented as a verified rural village.

## Disclaimer

SolarShakti is an academic prototype intended for preliminary renewable-energy assessment. Results are indicative and should not be used as a substitute for detailed engineering, financial, environmental, land-title, grid-connection, or feasibility studies.
